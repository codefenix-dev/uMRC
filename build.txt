** Building uMRC from Source **


Linux (x64 and arm64):

  Follow these steps to compile Linux x64 or arm64 binaries:

  1. First make sure gcc is installed on the system.

     On Debian systems like Ubuntu, open a Terminal and run:

       sudo apt install gcc


  2. Next make sure LibreSSL is installed on your system:

       sudo apt install libssl-dev

     (Refer to your distro's documentation on installing gcc and LibreSSL.)


  3. Make the build.sh script executable:

       chmod +x build.sh


  4. Finally, run the build.sh script:

       ./build.sh


  When done, you will find the compiled binaries and other necessary files
  in a subdirectory named "bin".

  [bin]:
  - [screens]
  - [themes]
  - setup
  - umrc-bridge
  - umrc-client




macOS (arm64):

  The same build.sh script that compiles binaries for Linux also compiles
  binaries for macOS for arm64.

  You will need to have LibreSSL installed. There are a couple different ways
  to go about installing on macOS. Installing via Homebrew may be the simplest
  method:

    https://formulae.brew.sh/formula/libressl

  Alternatively, you may download the latest source from libressl.org and
  follow the "Build steps using configure" directions included.

  When done, you should be able to run the build.sh script to make your own
  macOS binaries.

  1. First, make the build.sh script executable:

       chmod +x build.sh


  2. Finally, run the build.sh script:

       ./build.sh


  You will find the compiled binaries and other necessary files in a
  subdirectory named "bin", just as outlined above with Linux.




FreeBSD (x64 and arm64):

  Follow these steps to compile FreeBSD x64 or arm64 binaries:

  1. First make sure gcc is installed on the system.

     Open a Terminal and run:

       pkg install lang/gcc


  2. Next make sure bash is installed on the system.

     In the Terminal, run:

       pkg install bash


  3. Make the build.sh script executable:

       chmod +x build.sh


  4. Finally, run the build.sh script:

       bash build.sh


  When done, you will find the compiled binaries and other necessary files
  in a subdirectory named "bin".

  [bin]:
  - [screens]
  - [themes]
  - setup
  - umrc-bridge
  - umrc-client
  
  FreeBSD is the only targeted BSD. The above steps may work for OpenBSD and
  NetBSD as well, but they would need their own compiled OpenDoors library.
  



Windows (x86 & x64):

  You may use either MinGW or Microsoft Visual Studio to compile uMRC. Which
  one you choose is entirely up to you and your comfort level with either
  tool. If you've never used either, then the MinGW method is arguably easier
  and takes less time.
  

  Method #1 - MinGW:
  
  1. Install a standalone build of MinGW:
  
     https://winlibs.com
     
     Find the most recent POSIX ZIP option under Releases. There is both a 
     Win32 and Win64 version available. Download both and extract their contents
     to any folders of your choosing.
     
  
  2. Edit the build.bat file and change the path_to_x64_gcc and path_to_x86_gcc
     variables to match the actual paths where you extracted the ZIP file(s)
     
     
  3. Open a Command Prompt and go to the folder where you extracted the uMRC 
     project files and run build.bat (or just double click it). It will compile
     32-bit executables by default, or you can have it compile 64-bit 
     executables instead by running: build.bat x64
     
     build.bat will fail if you didn't specify your path variables properly in
     step #2.


  When done, you will find the compiled EXEs, DLLs, and other necessary files
  in a subfolder named "bin" within the uMRC folder.

  [bin]:
  - [screens]
  - [themes]
  - crypto-57.dll
  - ssl-60.dll
  - ODoors63.dll
  - setup.exe
  - umrc-bridge.exe
  - umrc-client.exe
  
  

  Method #2 - Microsoft Visual Studio:

  1. Download and install Visual Studio Community:

     https://visualstudio.microsoft.com/vs/community/

     uMRC was developed in Visual Studio Community 2022, but any version on or
     after 2017 will work fine. 
     
     Ensure you select the "Desktop Development with C++" option under 
     Workloads during install.     


  2. After Visual Studio is installed, start it and select the option
     to "Open a project or solution". Browse to "umrc.sln", and click Open.

     Alternatively, simply double-click on the umrc.sln solution file in
     Windows, and Visual Studio should open it automatically.


  3. In the "Solution Explorer" panel that opens, right click on
     "Solution 'umrc' (3 or 3 projects)" and select "Build Solution".


  When done, you will find the compiled EXEs, DLLs, and other necessary files
  in a subfolder named "Release" within the solution folder.

  [Release]:
  - [screens]
  - [themes]
  - crypto-57.dll
  - ssl-60.dll
  - ODoors63.dll
  - setup.exe
  - umrc-bridge.exe
  - umrc-client.exe

  Optional:

  If you wish to compile 64-bit executables, change "x86" to "x64" in the 
  Platforms dropdown near the top of the Visual Studio window, and then
  rebuild the solution (see step #3 above).

  You will find the compiled EXEs and DLLs in a subfolder named "x64\Release"
  within the solution folder. You may replace the x86 EXEs and DLLs with these.

  The only notable differences in the x64 executables are:
    - "Windows.x86_64" will be shown in your BBS's /info screen.
    - umrc-bridge uses the 64-bit LibreSSL libraries.
